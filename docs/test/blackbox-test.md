# ブラックボックステスト仕様書・実施結果

## 1. 概要

本ドキュメントでは、会員管理システムに対して画面操作を中心に実施したブラックボックステストの仕様と実施結果を記録します。

JUnit / Mockito による単体テストとは別に、利用者の立場から実際の画面・入力・画面遷移・権限制御・エラー処理を確認しています。

テスト観点の一覧は `test-matrix.md`、JUnit / Mockito による単体テストの詳細は `TESTING.md` を参照してください。

### 詳細画面へのタグ表示

ブラックボックステスト中、会員詳細画面にタグが表示されていないことを発見しました。

詳細画面へタグ表示を追加した後、以下を追加・再実施しました。

- `BB-DTL-005` タグ付き会員の詳細画面でタグが表示されること：OK
- `BB-DTL-006` タグなし会員の詳細画面が正常表示されること：OK

このため、今回のテストでは「テスト実施 → 改善点発見 → 実装修正 → テストケース追加 → 再テスト」まで実施しています。
